# JoyOPC V0.4 — Channel Commerce Runtime

## 目标

V0.4 的目标不是“再做一个商城”，而是让 JoyOPC 成为外部电商平台上方的 AI Commerce Control Plane。

```text
                    JoyOPC CEO Cockpit
                            │
                    AI Commerce Brain
                            │
        ┌───────────────────┼────────────────────┐
        │                   │                    │
 Product Intelligence   Channel Runtime      Profit Runtime
        │                   │                    │
 产品三区 Gate          Account / Publish      Cost Ledger
 CEO Approval           Order Sync             Reconcile
 Master Product         Idempotency             SKU Profit
        │                   │                    │
        └───────────────────┼────────────────────┘
                            │
                     Channel Adapters
            ┌───────────────┼────────────────┐
            │               │                │
         Shopify          Amazon         TikTok Shop
       Admin GraphQL      SP-API          Open API
```

## 数据边界

### JoyOPC拥有的真相

- Master SKU
- 产品三区
- 供应商与成本
- 跨渠道产品映射
- 跨渠道订单映射
- SKU贡献利润
- AI经营决策

### 外部渠道拥有的真相

- 平台 listing id
- 平台审核状态
- 平台 order id
- 平台成交/退款事实
- 平台结算与广告费用

JoyOPC通过 `ChannelObjectRef` / `ChannelOrderLink` 建立映射，而不把外部ID当自己的主键。

## ChannelAccount 安全边界

数据库仅允许保存：

```text
store_domain
seller_id
marketplace_id
shop_cipher
env_prefix
```

禁止保存：

```text
access_token
refresh_token
client_secret
app_secret
```

秘密信息只从运行环境读取。

## Publish Gate

```text
Master Product
  │
  ├─ HOLD / REJECT ──> BLOCK
  │
  └─ TEST / SCALE
         ↓
 Channel-specific validation
         ↓
 Adapter.publish_product
         ↓
 ChannelObjectRef
```

Amazon / TikTok 的类目属性由平台规则决定，JoyOPC不会根据商品名称猜测合规字段。

## Order Sync Idempotency

唯一业务键：

```text
(channel_account_id, external_order_id)
```

重复同步：

```text
找到已有 ChannelOrderLink
      ↓
保留 CommerceOrder
      ↓
替换 line items
      ↓
重新映射 Master SKU
      ↓
重新做成本对账
```

因此重试不会扩大订单数或GMV。

## SKU Profit Runtime

订单进入后先得到：

```text
Net Sales
Product Cost (MasterProduct.landed_cost × quantity)
```

随后 `ChannelCostEntry` 逐步补齐：

```text
Shipping
Platform Fee
Ads
Refund
Other
```

订单级成本按 line item 的净销售额权重分摊；SKU级成本直接命中SKU。

```text
Contribution Profit =
Net Sales
- Product Cost
- Shipping
- Platform Fee
- Ads
- Refund
```

`profit_quality` 用于告诉 CEO 这是不是已经完成对账的利润。

## Provider-specific notes

### Shopify

- Admin GraphQL 2026-07
- Product create: productCreate
- Variant price: productVariantsBulkUpdate
- Orders: GraphQL orders + lineItems

### Amazon

- LWA OAuth token exchange
- Listings Items API for SKU listing lifecycle
- Orders v2026-01-01
- Product Type Definition属性不能由JoyOPC臆造

### TikTok Shop

- HTTPS-only gateway
- v202309+ path versioning
- HMAC signing
- access token in `x-tts-access-token`
- Product API supports idempotency key
- category/rules/attributes/compliance must be retrieved per shop/market
