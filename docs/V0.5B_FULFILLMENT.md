# JoyOPC V0.5B — Inventory + Fulfillment + Dropship

Apply after V0.5A. This closes the physical-commerce loop for a sales-only OPC:

```text
Channel Order
  -> Fulfillment Allocation
  -> Own/3PL stock reservation OR Supplier Dropship Request
  -> Supplier ACK / Ready to Ship
  -> Shipment + tracking pushed back to channel
  -> Inventory consume / reservation release
  -> Outbox event for downstream finance and automation
```

Decision rule: prefer own/3PL ATP, else dropship supplier, else `EXCEPTION`. ATP = `on_hand - reserved - safety_stock`.

APIs: `/api/ops/overview`, `/api/ops/inventory`, `/api/ops/orders/{id}/allocate`, `/api/ops/fulfillments`, supplier ACK, ship, cancel.

`enqueue_outbox()` only flushes; callers own the commit so Outbox stays transactional.
