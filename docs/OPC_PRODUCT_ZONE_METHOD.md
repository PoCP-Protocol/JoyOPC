# JoyOPC 产品三区与经营哲学 OS

来源：经营哲学图「危机管理 / 追求卓越：前端铁三角 / 奔跑创业路上」+「优化三区图：分析客户基本面」。JoyOPC 把它从墙上的图变成可计算的经营系统。

```text
持续建立优势（先辨真伪）
        ↓
① 优化三区图     独占 / 优质 / 同质
        ↓
② 主要矛盾
        ↓
③ 谋略（六圈）→ ④ 谋略落地 → ⑤ 博弈（抓牌 / 出牌 / 换局）
        ↓
⑥ 客户：成为靠谱的人（四管理）
        ↓
⑧ 目标与考核  ←  ⑨ 人才 VALUE  ←  ⑩ 奔跑创业路上
```

优质区与代码中的 `ADVANTAGE`（优势区）是同一区：有组合优势、无绝对排他权。

## 1. 独占区

**定义**：对商品、销售权、IP、渠道、区域或关键供给具有**可验证**的排他控制权。

经营动作：保护价格与渠道边界；合同锁定期限/区域/平台/最低供货；内容与广告最高优先级。

## 2. 优质区（优势区）

**定义**：无绝对排他，但在成本、供应、内容、品牌、履约、市场理解中形成组合优势。

经营动作：小预算测试 → 过利润/转化阈值放量 → 监控优势衰减 → 争取升格独占。

## 3. 同质区

**定义**：可替代、价格透明、无控制权与组合优势。

**只做效率套利**（成本、内容转化、周转、获客、渠道红利）。条件不成立则淘汰，不为 GMV 打价格战。

## 4. 优化三区图（货盘，不是单品）

单品评分解决「这一款进哪一区」。第二张图解决「整个货盘的分布是否在吃利润」。

利润率沿独占 → 优质 → 同质下降。默认目标配比（哲学图优化后）：

| 区 | 危机盘示例 | 优化目标 |
|---|---|---|
| 独占 | 10% | 20% |
| 优质 | 20% | 30% |
| 同质 | 70% | 50% |

引擎用 SKU 占比、GMV 占比、分区均毛利、配比加权组合毛利，对比目标配比，给出调仓动作。市场信号只能修正需求/竞争，**不能**改写三区战略。

实现：`analyze_portfolio()` / `GET /api/operating-os`。跨境 AI 玩具拆解见 `docs/CROSSBORDER_AI_TOY.md`。

## 5. 持续建立优势：先辨真伪

左侧「伪优势 / 自嗨型优势 / 创造优势」必须进决策，否则优质区会被自评污染。

| 类型 | 判定 |
|---|---|
| 伪优势 | 独特性/品牌自评高，无排他权，竞争已内卷，渠道与成本壁垒弱 |
| 自嗨型优势 | 内容/品牌高，客户基本面（需求）并未买单 |
| 创造优势 | 控制权、改变认知、改变模式、成本投资、保供、超级体验 |

伪优势商品不得按独占投入。

## 6. 前端铁三角

1. **优化三区图**  
2. **主要矛盾**（价格战 / 伪优势 / 优势被复制 / 独占不足 / 靠谱缺口 / 谋略未落地）  
3. **谋略 → 落地 → 博弈**

博弈三招：抓牌（锁资产） / 出牌（验证后打点） / 换局（淘汰同质、迁配比）。

## 7. 谋略六圈

危机预警圈 · 保供圈 · 利润步行圈 · 认知拉齐圈 · 质量圈 · 生态圈。

圈分为 HEALTHY / WATCH / ALERT。ALERT 时经营阶段回到「危机管理 / 优势转换」，而不是加投放。

## 8. 客户：成为靠谱的人

靠谱分 = 承诺（独特性+内容对齐）+ 交付（供应）+ 质量（退货反向）+ 合规。  
四管理不及格时，主要矛盾是靠谱缺口，先于投放。

## 9. 系统化对象

单品：`ProductZoneEngine` + `SkuPhilosophy`（区、机会分、决策、优势真伪、主要矛盾、谋略、落地、博弈、靠谱分）。

货盘：`MixPolicy`（默认同图：20 / 30 / 50）+ `analyze_portfolio`。

发布 Gate 不变：`HOLD` / `REJECT` 不能进真实渠道。同质区占比超过警戒线时，经营OS会拒绝再向渠道放量（换局优先于上架）。

## 10. 融于平台管理过程

墙上的 ①–⑩ 对应 JoyOPC 每周经营节奏，而不是独立方法论页面。

| 过程 | 平台落点 |
|---|---|
| 持续建立优势 | 选品评估拆伪优势/自嗨/创造优势；SCALE 会被降为 TEST |
| ① 优化三区图 | `GET /api/operating-os` 配比 vs 20/30/50 |
| ② 主要矛盾 | CEO Cockpit / 经营OS 头条；决定本周过程步骤 |
| ③④⑤ 谋略落地博弈 | CEO 批准候选后生成带 VALUE 标签的 AI 任务（抓牌/出牌/换局） |
| ⑥ 靠谱 | 靠谱分进入考核；质量圈告警则先四管理 |
| ⑧ 目标与考核 | 六项 KPI：三区占比、组合毛利、伪优势件数、靠谱缺口 |
| ⑨ 人才 VALUE | Buyer=优势，CFO/定价=价值，Merchandiser=落地，产品智能=靠谱，Market=进化 |
| ⑩ 奔跑 | 配比健康且无告警圈时进入此阶段，重点保护独占、验证优质 |

闸门：

- **批准**：同质区 + 配比已超警戒 + SCALE → 409 拒绝；伪优势 SCALE → 降为 TEST。
- **发布**：在原三区 Gate 上叠加换局规则。
- **任务**：Workforce 按 VALUE 分工，而不是平铺工单。

## 11. ProductUnit 护照（AI 玩具整机）

选品原子不是纯货架 SKU，而是 **魂配方 × 模组档位 × 外形壳**（吸收 JoySoul）：

- 无人设或无记忆 → 同质区（套壳问答）。
- `hw_gen` 已认证能力覆盖不了声称特征（Gen1 声称摄像头/肢体）→ 不得独占，最高优质区。
- 认证缺口未齐 → 不得 SCALE；DRAFT 可挂，真实放量返回 `REQUIRES_CERT`。
- `memory_enabled` 默认关，对应儿童数据 consent。

实现：`app/product_unit.py` + `ProductZoneEngine` 硬门 + `MasterProduct`/`ProductCandidate` 护照字段。
